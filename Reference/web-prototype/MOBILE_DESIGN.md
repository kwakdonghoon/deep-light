# Abyss Keeper — 모바일 설계서

## 1. 플랫폼 결정
| 항목 | 결정 | 이유 |
|---|---|---|
| 방향 | **가로 고정** | 한 손 이동 + 한 손 행동 구조에 맞고, 탑다운 시야가 넓다. 세로면 "가로로 돌려주세요" 안내 |
| 논리 해상도 | **높이 180px 고정, 폭은 기기 비율에 맞춰 288~428px** | 16:9~21:9 폰 모두 레터박스 없이 채움. 픽셀 크기가 기기마다 같아 시야가 공평 |
| 확대 | 화면 높이 ÷ 180 (nearest-neighbor) | 1080p 폰에서 6배 |
| 안전영역 | 노치/제스처바 `safe-area-inset-*` 만큼 HUD 안쪽으로 | 버튼이 잘리거나 시스템 제스처와 겹치지 않게 |
| 프레임 | 60fps 목표, 탭 비활성/앱 전환 시 자동 일시정지 + 저장 | 배터리, 전화 수신 대응 |

## 2. 화면 구성 (가로, 높이 기준 vh)
```
┌──────────────────────────────────────────────────────────────────┐
│ [체력 ███████]      [● 12 ● 3 ● 0 ● 2 ● 5]          [II] ┌─────┐ │
│ [산소 ███░░░░]        (자원 칩, 상단 중앙)                 │미니맵│ │
│ 구역: 얕은 폐허      [토스트 / 보스 체력바]                │ 탭=확대│
│                                                           └─────┘ │
│                                                                   │
│     (월드 터치 영역: 가까운 타일을 길게 눌러 정밀 채굴)      [❤]    │
│                                                         [◎]       │
│   ○ ← 조이스틱 영역(화면 왼쪽 42%)           [🔨제작]   [💡]  ⛏   │
│   (처음 누른 곳에 생김)                     (비콘 근처만)    (큰 버튼) │
└──────────────────────────────────────────────────────────────────┘
```
- **왼손잡이 모드**: 조이스틱 영역과 행동 버튼 클러스터를 좌우 반전 (메뉴에서 토글, 기억함)
- 자원은 아이콘+숫자 칩으로 줄여 시야를 가리지 않음. 램프/환기구/젤 수량은 해당 버튼 배지로 표시

## 3. 조작
| 입력 | 동작 |
|---|---|
| **플로팅 조이스틱** (왼쪽 42%) | 누른 위치에 생성, 데드존 18%, 반경 = 화면 높이의 12% (36~64px), 아날로그 속도 |
| **⛏ 행동 버튼** (우하단, 지름 24vh) | 누르고 있는 동안: ① 가까운 적(30px 이내)이 있으면 자동 조준 공격 ② 없으면 바라보는 방향 앞의 타일 채굴/상자 열기/조개 줍기 |
| **월드 터치** (나머지 영역) | 누른 타일(닿는 거리 안)을 정밀 채굴. 드래그하면 대상 변경. 설치물 회수도 여기서 |
| 💡 / ◎ | 앞 칸이 바닥이면 앞에, 벽이면 내 위치에 램프 / 환기구 설치 |
| ❤ | 젤 2개로 체력 3 회복 |
| 🔨 제작 | **비콘 근처에서만 나타남**. 살 수 있는 게 있으면 맥박처럼 깜빡임 |
| II | 일시정지 메뉴 (이어하기, 소리, 전체화면, 왼손 모드, 새 게임) |

**자동 조준 규칙**
- 바라보는 방향 = 조이스틱 방향 (놓으면 마지막 방향 유지)
- 타일 탐색: 플레이어 중심에서 바라보는 방향으로 6→32px, 4px 간격 광선. 처음 만나는 벽/광맥/상자/조개가 대상
- 설치된 램프/환기구는 자동 대상에서 제외 (방금 놓은 걸 바로 줍지 않도록). 회수는 월드 터치로만

**터치 타깃 크기**: 작은 버튼은 `max(48px, 13vh)`, 행동 버튼은 24vh, 메뉴 버튼은 최소 40px. 높이 360px 기기에서 작은 버튼은 48px
**터치 보정**: 터치 모드에서는 작살 사거리를 26→36px로 늘려, 첫 타격 넉백으로 적이 밀려나도 버튼만 누르고 있으면 연타가 이어지게 함 (테스트에서 발견한 문제)

## 4. 제작 시트 (모바일)
- 가운데 모달, 2열 카드 그리드 (카드 1장 = 이름 / 효과 변화 / 필요 재료 칩)
- 살 수 있는 카드는 초록 테두리, 최대 등급은 회색, 재료 부족은 빨간 칩
- **카드를 한 번 탭하면 즉시 제작** (확인 팝업 없음 — 비콘 안이라 되돌릴 일이 적고, 재료는 이미 눈에 보임)
- 열려 있는 동안 게임 일시정지 (닫기 버튼으로 복귀)

## 5. 일시정지 / 앱 생명주기
- 메뉴·제작 시트가 열리면 월드 정지, 입력 초기화
- 탭이 숨겨지면(`visibilitychange`) 즉시 저장 + 메뉴 열림
- 저장: 10초마다 / 제작 시 / 숨김 시 (모바일 브라우저는 `beforeunload`가 불안정하므로 `visibilitychange`를 신뢰)

## 6. 햅틱 / 사운드
- 진동: 피격 40ms, 제작 15ms, 상자 20ms (지원 기기만, 설정에서 끄기는 TODO)
- 소리: 첫 터치에서 오디오 컨텍스트 시작 (모바일 자동재생 정책)

## 7. 아직 하지 않은 것 (설계만)
| 항목 | 메모 |
|---|---|
| 픽셀 폰트 | **적용됨**: Galmuri14(주요 글자) + Galmuri11(보조 글자), 원래 크기의 정수배만 사용(폰 1배, 큰 화면 2~3배). 라이선스 OFL 1.1은 `assets/fonts/Galmuri-OFL-LICENSE.txt`. 용량 약 1MB(woff2 2개) — 출시 전 쓰는 글자만 추리면 더 줄일 수 있음 |
| 아이콘 보강 | 산소통(병처럼 보임), 추진 핀(삼각형처럼 보임)은 임시 수준. 아티스트 마감 필요 |
| 세로 모드 | 지원 안 함. 필요하면 시야를 위/아래로 늘리고 조이스틱·버튼을 하단에 가로 배치 |
| 앱 아이콘 / 스플래시 | PWA 매니페스트에 SVG 임시 아이콘만 있음 |
| 접근성 | 조이스틱 크기/투명도 슬라이더, 진동 끄기, 버튼 크기 옵션 |
| 실기기 검증 | **브라우저 에뮬레이션만 확인**. 실제 손가락 크기, 엄지 도달 거리, 멀티터치(조이스틱+행동 동시)는 실기기 테스트 필요 |

## 8. 디자인팀 검토 반영 (UX 디자이너 + 아트 디렉터 역할 검토)
기준 문서: `claude-code-game-studios`의 `ux-designer`, `art-director` 역할 정의, `hud-design` / `accessibility-requirements` 템플릿.

| 영역 | 반영 내용 |
|---|---|
| 조작법 | 시작 화면을 아이콘 3줄로 축소(글자 12px 이상, 배경 불투명도 .95). 첫 이동 → 첫 채굴 순서로 한 번씩 힌트 토스트. 일시정지 메뉴에 **조작법 보기** 추가 |
| 행동 버튼 | 이모지 → 픽셀 아이콘. 큰 버튼은 **적이 가까우면 작살, 아니면 곡괭이**로 아이콘 전환. 보조 버튼 56px 이상, 간격 5px 이상. 수량 0이면 흐리게, 회복 배지는 **사용 가능 횟수(xN)** |
| 제작 UI | 아이콘 카드, **보유/필요** 표기(부족한 재료만 빨강). 업그레이드는 **카드 선택 → 카드 안 `제작` 버튼**의 두 단계(실수 탭 방지), 소모품은 한 번에. 8장 한 화면. 제작 결과 메시지는 시트 안에 표시(토스트가 시트 뒤에 가려지는 문제) |
| 게임 화면 | 9-슬라이스 픽셀 프레임(`art/frames.px.js`), 자원 칩은 모양이 다른 아이콘. 저체력/저산소는 **색 + 깜빡임 + 느낌표**(색만으로 알리지 않기). 구역 전환 토스트. 타깃은 코너 브래킷(닿으면 맥동, 안 닿으면 빨강 X). 조명 밴드 알파 균등화, 미니맵 플레이어 점멸 |
| 화면 비율 | 4:3 쪽(태블릿, 데스크톱 창)에서 HUD가 부딪히지 않도록 축소 |

**아트 제작 파이프라인**: `art/icons.px.js`, `art/frames.px.js` → `claude-pxl`로 빌드 → `assets/*.png`. 버튼/프레임은 월드 픽셀 한 칸(`--px` = 화면 높이/180)의 정수배로 그려 월드와 격자를 맞춘다.

## 9. Unity 이식 대응
| 웹 프로토타입 | Unity |
|---|---|
| 플로팅 조이스틱 | Input System `On-Screen Stick` (또는 자체 구현) + 터치 영역 |
| 행동 버튼 / 자동 조준 | `On-Screen Button` + `AutoAim` 컴포넌트 (규칙은 3장 그대로) |
| 폭 288~428 가변 | Pixel Perfect Camera + 카메라 `orthographicSize` 고정(높이 180px), 폭은 자동 |
| `safe-area-inset` | `Screen.safeArea` 기반 SafeArea 컨테이너 |
| 제작 시트 | uGUI Grid Layout + 카드 프리팹 |
| 햅틱 | `Handheld.Vibrate()` / 플랫폼별 Haptics 플러그인 |
